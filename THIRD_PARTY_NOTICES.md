## knoellle/wfinfo-ng

- Source: https://github.com/knoellle/wfinfo-ng

## glowseeker/cephalon-kronos

- Source: https://github.com/glowseeker/cephalon-kronos
- License for the application code used here: MIT
- Scope: `warframe_mem_log.py` is a Python port/adaptation of the native
  process-memory region scan, EE.log ring-buffer discovery, and line-hash
  deduplication approach in Cephalon Kronos's `memory_scan.rs`/`mem_reader.rs`.
- Note: Cephalon Kronos's license file applies a Commons Clause condition to
  its separately bundled `warframe-api-helper` binary. This repository does
  not treat that binary as MIT code; normal installs obtain the helper from
  its publisher, Sainan, under the publisher's terms.

## calamity-inc/browse.wf

- Source: https://github.com/calamity-inc/browse.wf
- License: MIT
- Scope: `_roll_perfectness()` in `riven_grader_watcher.py` adapts the integer
  Riven-stat perfectness decoding used by browse.wf's Riven parser. The local
  S-grade boundary used for the "God Roll" display label follows browse.wf's
  `floatToGrade()` boundary; stat-tag reductions and all other grade-selection
  rules remain project-specific.

## WFCD/WFInfo

- Source: https://github.com/WFCD/WFInfo
- License: Apache-2.0
- Scope: reference implementation and design lineage for relic reward OCR and
  companion-app behavior. No claim is made that the current Python overlays
  reproduce WFInfo's UI or current feature behavior exactly.

## Digital Extremes public export

- Source: https://content.warframe.com/PublicExport/index_en.txt.lzma
- Scope: `riven_name_fragments.json` is generated by joining the randomized-mod
  localization keys preserved in the cleaned `ExportUpgrades.json` cache with
  the corresponding English `prefixTag` and `suffixTag` values in DE's current
  official `ExportUpgrades_en.json`. The game-patch updater regenerates and
  validates this derived cache; no wiki or third-party parser table is copied.
