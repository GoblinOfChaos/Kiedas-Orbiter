# Wiki module scrape test pages

This is an isolated comparison of the Markdown output produced by
[`420gaming420/wf-wiki-module-scripts`](https://github.com/420gaming420/wf-wiki-module-scripts)
from two rendered pages on the official WARFRAME Wiki:

- `Module:Ability/data`
- `Module:Warframes/data`

The samples use the upstream `dev` scripts at commit
`2dd698bcdbfdb009da424dfa0706bdd823059c1a`:

- `request.py` to build the module/timestamp caches
- `download.py --page` to fetch only the two selected modules
- `extract_text.py --force` to create the Markdown pages

The `.html` files are the rendered Wiki responses. The `.md` files were
generated by the upstream repository's `extract_text.py`; their metadata files
record the Wiki revision timestamp and extraction time. No application source
or existing `wiki_*` directory was modified.

Each Markdown sample contains frontmatter, headings, tables, links, and Lua
fences. The upstream extractor currently writes `Module/Ability/data` and
`Module/Warframes/data` in its frontmatter `wiki_url` values, while the source
HTML and Wiki links retain the canonical `Module:...` page names; this is left
unchanged so the samples reflect the upstream output exactly.

Source URLs:

- https://wiki.warframe.com/w/Module:Ability/data
- https://wiki.warframe.com/w/Module:Warframes/data

The Wiki data remains subject to the WARFRAME Wiki's licensing and attribution
requirements.
