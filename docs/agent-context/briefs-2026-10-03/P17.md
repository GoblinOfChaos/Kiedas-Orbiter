## Problem (verified on the user's real data)
The Vendor tab shows nothing. `buildPreviewPlaceIndex` (screenModel.js ~line 203) builds vendor places from `wikiVendorIndex`: `for (const [item, entries] of wikiVendorIndex ...) for (const entry of entries) add(entry.itemName ?? item, { type: 'vendor', source: entry.vendor ?? entry.name ?? 'Vendor' })`. On the real data `wikiVendorIndex` is a Map of 2,482 items whose values are LISTS OF VENDOR NAMES (strings), e.g. `["Acrithis","Nightwave"]`, so `entry.vendor` and `entry.name` are undefined on a string and every source becomes the fallback 'Vendor': the result has exactly ONE vendor place named "Vendor" (place types on the real data: mission 905, enemy 923, conclave 15, relic 800, vendor 1). The DE vendor offers (`exportVendorIndex`, a Map of 1,870 items, built in src/lib/acquisitionInfo.js `buildExportVendorIndex`; inspect its value shape) are not used by the place index at all, although the item drawers use them for "sold by ...". In `farmNext.js` the tab filter is `vendors: new Set(['vendor'])`.
