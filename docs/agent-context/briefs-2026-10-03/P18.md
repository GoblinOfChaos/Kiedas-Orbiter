## Problem
After the item 46 change the keys work, but End does not go to the end of the whole list: it goes to the end of what is currently rendered. Cause NOT verified. What is known: the End target is `scrollHeight - clientHeight` of the scroll container; the list is windowed (the virtual root has height `rowCount * stride + 16`, rows are drawn in a window at `top: firstRow * rowStride`); there is no "load more" step; CSS smooth scroll is forced off (`scroll-behavior: auto !important`); the stride is MEASURED from the first rendered row and re-measured by the calibration effect after resize/tab/view/stride changes (the measurement setState changes the root height); window metrics are updated by a throttled (50 ms) scroll handler. Hypotheses: (1) the stride is re-measured during the jump (the first rendered row after the jump can be a row whose cards are taller or shorter), the root height changes while the window moves and the position is clamped before the new window renders; (2) the target is computed once from the old height; (3) another list branch (Sets, Ayatan, Arcane, list view) behaves differently.
