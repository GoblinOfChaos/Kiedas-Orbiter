## A. Item 51: wrong Common/Uncommon/Rare tiers on Prime part drawers
Verified: DE `ExportRelics` is the authority (Nidus Prime Chassis Blueprint is RARE in all 6 of its relics; the Nidus Prime main Blueprint is UNCOMMON). `buildRelicRarityIndex` (relicSources.js) keys tiers by `relic name | reward path` where the reward path is the BLUEPRINT path (`.../NidusPrimeChassisBlueprint`), but the Crafting-requirements part rows look up the COMPONENT path (`.../NidusPrimeChassisComponent`), so the lookup misses and `normalizeRelicSources` falls back to `source.rarity` from the bundled item data (`wfcd-combined.json`), which is unreliable (it labels the 25.33% Common rate 'Uncommon'; for Nidus Prime Chassis it labels the 10% row Uncommon and the 2/4/6% rows Rare).
