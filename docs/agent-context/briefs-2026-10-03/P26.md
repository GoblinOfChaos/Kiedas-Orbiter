Fix `resolveNode` so that when `entry.name` is not a dictionary key and is a non-empty literal string that is not itself a path (`/Lotus/...`) or a raw id, it is used as the name; keep the English path unchanged. Same for the planet. Check every other place that does `dict[entry.name]` on ExportRegions records (grep for `ERg[` and `.regionName`, `.systemName`; the Dashboard Steel Path Incursions card, Invasions card (worldstateParser.js ~line 582), fissures, arbitrations, sorties, Nightwave...).
