## Part 1: planet on node rows (item 69)
`sourcePlace()` in src/lib/farmingTargets/screenModel.js sets `planet: source.region ?? source.planet ?? null` only from the drop row. It already finds the node's region record (`regionForSource`, used for the faction). Take the planet from that region record when the row has none (the record's `systemName`, which may be a dictionary key such as `/Lotus/Language/Locations/Ceres` or already a literal localized name; resolve it with `resolveNode(...)` like the faction, and apply the same literal-name rule as src/lib/warframeUtils.js `resolveNode` after job P26). Places that are not nodes (bosses, caches, events: Corrupted Vor, Alad V, Hallowed Flame caches) must carry an honest kind label shown instead of a blank (use existing translated strings if the app has them, otherwise add new keys to ALL 14 locale files with real translations: see tests/i18n for the enforcement). 'Group by planet' (groupRankedByPlanet in src/lib/farmingTargets) must put every node place into its planet group; non-node places go into a clearly named group, never an empty-named one. Tests on the user's real 31 targets: every place of kind node has a planet; a before/after count (76 of 100 mission places had none).

## Part 2: safe loading of big lists (item 67, mitigation)
In the Farming Targets screen (src/screens/FarmingTargets.jsx, PreviewFarmingView): render only the first 40 ranked places, with a translated "Show more (N)" button that adds 40 at a time; render the per-place item chips collapsed when a place has more than 6 (a "+N" toggle); keep the totals and the ranking untouched (the model stays complete, only the rendering is paged); the paging state resets when the tab or filters change. Memoize rows (React.memo with stable props) so typing in the search box or opening a drawer does not re-render every row. Add a render-count/size check in a test (server-side render of PreviewFarmingView with the 31 real targets: assert the number of rendered place rows is at most 40 on first render and that "Show more" appears).
