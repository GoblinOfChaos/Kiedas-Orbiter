(In 't()', 't' is 41)" as soon as the user leaves a screen (Farming Targets to Inventory). The app log (`~/.local/share/kiedas-orbiter-preview/data/user/logs/app-2026-10-04.log`, 13:41:03) shows `t is not a function. (In 't()', 't' is 41.99999999999909)` with the component stack `PageLayout (UI chunk) in FarmingTargets`.

## Cause (read it yourself and verify)
Job P28 added to `PageLayout` in src/components/UI.jsx line ~206: `useEffect(() => screenMountRef.current?.tracker.complete(), [route]);`. The arrow returns the value of `complete()`, which is a NUMBER (`durationMs`, e.g. 41.99999999999909). React treats an effect's return value as its cleanup function, so when the screen unmounts or the route changes React calls the number as a function: "t is not a function". The server-side-render tests never run effects, so nothing caught it.
