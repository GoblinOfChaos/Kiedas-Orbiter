## Output (exact schema, one file per job)
`src-tauri/data/assets/data/verified-routes.<GROUP>.json` = `{ "<uniqueName>": { "name": "<display name>", "routes": [ { "kind": "drop|vendor|market|quest|event|crafting|reward|not_obtainable", "text": "ONE short sentence, current availability, no history/dates/update numbers, in English", "place": "<node, enemy, vendor, activity>", "price": { "amount": 0, "currency": "Platinum|Credits|Standing|Ducats|..." }, "chance": 0.0, "source": { "archive": "wiki_pdf_archive", "page": "<Page title>", "url": "https://wiki.warframe.com/w/<Page_title_with_underscores>", "quote": "an exact sentence or table line from the page text" } } ] } }` (omit `price`/`chance` when the page has none; one route per object; several routes allowed; a route's `text` is generated from the facts of its quote, never longer than 200 characters) and `src-tauri/data/assets/data/verified-routes.<GROUP>.unresolved.json` = `{ "<uniqueName>": { "name": "...", "reason": "no wiki page mentions it | page says nothing about obtaining | ambiguous ..." , "pagesChecked": ["..."] } }`. Every item of your scope must appear in exactly one of the two files.
