# P46 - make DE's official drop tables a drop-in source for dropsParser (NO flag flip, NO build)

## Why
The app's drop index (src/lib/dropsParser.js `processDropsAll`) is built from DropsAll.json, a third-party mirror (drops.warframestat.us).
The app already has a reader for DE's own page https://www.warframe.com/droptables (src/lib/deDropTables/parse.js) and a converter
`convertDeDropTables` (src/lib/deDropTables/convert.js) that is meant to emit the legacy DropsAll shape. It is switched off
(`DE_DROP_TABLES_ENABLED = false`; Rust `DE_DROP_TABLES_REFRESH_ENABLED = false`). Verified 2026-10-05: with the converter output,
`buildDropIndex` CRASHES (`dropsParser.js:474 group.rewards is not iterable`) and 12 sections differ in shape.
DE chances equal the mirror's exactly (0 differences over 6,441 shared mission rows); DE rarity words are more precise
("Ultra Rare", "Very Common" where the mirror says "Rare", "Common"); DE place names are cleaner. Keep DE's words.
IMPORTANT: DE's relic-reward rarity labels in this page are chance-bracket labels ("Uncommon (25.33%)" for a COMMON part). Relic rarity
must NOT be taken from the drop tables anywhere (tests/relics/relicRarityMatchesDe.test.mjs guards the displayed rows; keep it green).

4. deimosRewards / zarimanRewards / entratiLabRewards / hexRewards: old rewards are keyed A/B/C (rotation) with a `stage` field on each entry; new keys are stage names. Match the old contract.

Make the consumer keep working: when DE data is used, syndicate rows must come from the existing non-drop sources (look at acquisitionInfo.js buildSyndicateIndex / ExportSyndicates), or document exactly what is lost, with evidence.
