# P48 - polite, resumable downloader for ALL wiki.warframe.com article wikitext (NO real network calls from you, NO build)

## Why
The app's acquisition data is assembled from ~20 derived files and misses items (e.g. the Baro relics Axi A2/A5/V8/M5/Neo O1 have no source on their Intact card).
We need the wiki's own article text for every page, stored raw, so a later job can compare every app item with its wiki page. The existing local copies are unusable:
wiki_pdf_archive/* (PDF -> text lost table structure) and wiki_article_wikitext/ (only 2,435 pages). scripts/wiki-store/ only handles Lua modules - do not reuse it.

## Task (Node 24 ESM, no new dependencies, use global fetch)
Create `scripts/wiki-download/download.mjs` (+ small helper modules if useful) and tests in `tests/wiki-download/`.
CLI: `node scripts/wiki-download/download.mjs <outDir> [--limit N] [--titles file.json]`. Output in outDir:
- `pages.jsonl`: one JSON object per line: {title, pageid, revid, timestamp, wikitext}. Append-only; on restart skip titles already present with the same revid.
- `redirects.json`: {"<redirect title>": "<target title>"} for namespace 0 (from list=allredirects).
- `manifest.json`: {fetchedAt, apiBase, counts, userAgent, version}. `state.json`: continuation tokens so an interrupted run resumes.
API (MediaWiki 1.45, https://wiki.warframe.com/api.php, format=json, formatversion=2):
- Pages + wikitext in batches: `action=query&generator=allpages&gapnamespace=0&gapfilterredir=nonredirects&gaplimit=50&prop=revisions&rvprop=ids|timestamp|content&rvslots=main&maxlag=5`, follow `continue`.
  (If `--titles` is given, use `titles=A|B|C` batches of 50 instead.)
- Redirects: `list=allredirects&arnamespace=0&arprop=title|ids&arlimit=500` (follow continue) and resolve targets via `arprop=title` + `artitle` as MediaWiki returns them; check the real response shape in the API docs and handle it defensively.
Politeness (hard requirements): ONE request at a time, minimum 1.2 s between requests, `User-Agent: kiedas-orbiter-research/0.1 (jacob.lewis.edwards@gmail.com)`, honour `Retry-After` and maxlag errors (back off with the given/exponential delay, max 5 retries then stop with a clear error), stop immediately on HTTP 403/429 repeated twice, never run unthrottled loops. Log one progress line per 10 requests.
Validation before declaring success: no duplicate titles, every record has non-empty wikitext (record empty ones in `empty.json`, do not drop silently), counts printed.
Tests (node:test, mock `fetch` via an injectable client; DO NOT call the real wiki): batching and continuation, resume skips unchanged revids and refetches changed ones, redirect map, maxlag/Retry-After backoff, 429 twice -> stop, rate limit spacing (use an injectable clock/sleep), JSONL round-trip.
Do not touch src/, src-tauri/, or any app data. Add a short `scripts/wiki-download/README.md` (usage, license note: wiki text is CC BY-NC-SA 3.0 - keep attribution in manifest).
Write AGENT_REPORT.md as COMMON.md says.
