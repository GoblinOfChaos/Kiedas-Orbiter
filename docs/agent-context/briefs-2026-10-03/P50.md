## Task
Write `scripts/wiki-audit/make-verified-routes.mjs` that selects the CLEAN core from audit-report.json: status `app_missing` AND `appSources.unresearched` AND at least one wiki fact whose `detail` is a real sentence (length > 25, not a template name/param such as "DropLocations", "Acquisition |...", "{{...", "!Image", "|...") ; then for each item produce a verified-route entry in the existing schema, appended to the correct existing file family WITHOUT touching existing entries (no duplicates; skip items already present). Rules (Rule #1 of AGENTS.md: no guessing):
- Each route's `text` is a short, clean, current-route sentence derived ONLY from the wiki fact; `kind` from the existing vocabulary (vendor/market/prime_access/event/quest/drop/craft/not_obtainable...: check what the code accepts); `place` the named vendor/event/syndicate/location when explicit.
- `source` = {archive:"wiki_store", page:<title>, url:<wiki url>, revid:<revid from /home/jedwards/kiedas-orbiter/wiki_store/pages.jsonl>, quote:<VERBATIM substring of that page's wikitext>}. Drop the number (say "Purchasable from the Market.") or skip the fact; list every such skipped/partial item in a report `wiki-routes-skipped.md` with the reason.
