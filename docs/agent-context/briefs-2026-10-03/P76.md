## Task
For each of the 109 rows, write one row with these columns:
1. Report name.
2. Original uniqueName (exact).
3. Canonical DE identifier, only if different from column 2 (else "same"). For the four legacy identifiers (Glyph Prism, Last Chance Offerings, Varzia's Offerings, Varzia's Offerings - Part 2), look under `/Lotus/Types/StoreItems/...` in the exports and record the current identifier with status alias_resolved if the display name matches exactly.
4. DE files containing the exact identifier (file names only).
5. Recipe: yes/no, with the recipe record name if yes. A recipe is NOT an acquisition source.
6. DE source evidence: file, field and verbatim value for any field that states where the item is obtained. Else "none".
7. Wiki evidence: page title (after redirects), section heading, and a verbatim quote (max 30 words) that describes how the item is acquired, with the page timestamp. Flavor or description text is NOT an acquisition quote; if only flavor text is found, write "no acquisition text found". If the page is not in the dump, write "not in dump".
8. App route: the matching key in `src/lib/acquisitionData.js` (exact key text), else "none". Note any mismatch with the report name.
9. Status: one of catalog_only, recipe_found, direct_de_source, wiki_source, alias_resolved, unresolved.
10. Grade: Pass (acquisition source found and quoted), Fail (identity found, no acquisition source found), Blocked (lookup could not be completed; say why), Not Applicable (say why).
11. Notes.
