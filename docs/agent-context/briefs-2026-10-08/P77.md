# P77 — re-check the 133 Fail rows for acquisition text on wiki sub-pages

## Why
A previous check marked items Fail with "no acquisition text found", but it only read each item's main wiki page. Many items keep their acquisition text on sub-pages (for example "Amesha/Main", "Dagath/Main", "Dethcube/Main", "Carrier/Main"), or the main page uses a different name. The wiki dump holds that text, so these Fails are probably wrong.

## Input
- docs/agent-context/reports/no-acq-research-ALL.md — every table row whose grade column is "Fail" (133 rows across the three "## Part" sections). Columns: name, uid, canon, files, recipe, DE evidence, wiki evidence, route (parts 2–3 only), status, grade, notes.
- wiki_store/pages.jsonl and wiki_store/redirects.json.

## For each Fail row
1. Find pages whose title equals the item name, the name plus "/Main", or the name plus "/" plus any sub-page. Check redirects.json for the name. Use `grep -F '"title":"<Title>"'` to locate lines.
2. Search those pages' wikitext for acquisition wording: research, purchase or Market, drop or dropped by, reward, vendor, Tenno Lab, Dojo or Clan Dojo, Hollow, given or awarded, crafted from. Count only a sentence that names this item (or its blueprint or components) and states HOW it is obtained. Flavor text, stats, and "used in" or "spent on" text do not count.
3. Record the page title, the verbatim quote, and the quote's exact grep count.
4. Propose a grade:
   - "Pass" only if a verbatim quote states the acquisition route for this item.
   - "Fail (confirmed)" if the item page, its /Main sub-page and any redirects contain no acquisition sentence.
   - "Unclear" if the only text is ambiguous, or the item name appears only inside another item's page.

## Output
Write ONE new file: docs/agent-context/reports/no-acq-fail-recheck.md containing:
- A short summary: rows checked, and counts for Pass, Fail (confirmed) and Unclear.
- One table with columns: Item | uid | Page title holding the text | Verbatim quote | Grep count | Proposed grade | Note.
- A list of any Fail rows that could not be processed, with the reason.

## Do not
- Change grades, notes, or any existing report.
- Change app code or add any item to the app.
- Guess a route. If a quote cannot be copied from the dump, the grade is not Pass.
