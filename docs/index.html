Getting Started

  1. Navigate to the releases page.
  2. Download the binary for your OS (.exe for Windows, .AppImage or .deb for Linux, .dmg for macOS).
  3. Run setup (Windows) / Move into own folder and run (Linux/macOS).

How It Works

Inventory Scanning

warframe-api-helper reads session credentials from Warframe process memory, then fetches inventory from Digital Extremes' mobile API.

Real-Time Overlays and Notifications

A C++ addon to warframe-api-helper reads Warframe's in-memory EE.log ring buffer and streams log lines to the app. When the unique ingame trigger is detected, the app fires the overlay or notification.

Riven Price Prediction

Based on WarframeRivenPricer, the ONNX neural network estimates platinum prices based on weapon, equipped stats, and reroll status. Trained on warframe.market auction data, it outputs a price estimate, grade, expected value and potential for rerolling.

Privacy & Security

No sign-up required. No telemetry recorded. Everything is stored locally.
Does not modify game files or inject code.

  • Session credentials read from memory only to fetch inventory from Digital Extremes API.
  • Network requests: public game data exports, world-state APIs, warframe.market pricing.

Troubleshooting

"My inventory is empty!"
This is expected on first startup. Run a manual scan in Settings or enable live monitoring.

"Do I have to turn on Live Monitoring?"
No, you can also do manual scans in Settings. Data persists across sessions, just not updated constantly.

"The overlay doesn't appear during fissures."
1) Confirm that notifications/overlays work via the test buttons in settings.
2) Make sure all your settings (EE.log path, UI scaling etc.) are correct and that the log scanner has latched on to Warframe.
3) Check if Riven overlays work ingame.
4) If all the above work as expected but the overlay still fails, check overlay_debug.log in the data/user/ folder and report it on the issues page.

"I found a bug!"
Great, please report it on the issues page!
