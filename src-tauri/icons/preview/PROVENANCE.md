# Preview icon provenance

The existing repository `src-tauri/icons/icon.png` is embedded unchanged in `badge.svg`. A plain rectangle and the word PREVIEW are drawn over it for build identification. SVG rasterization uses rsvg-convert; platform formats use the local Tauri icon command. No generative image model or AI-generated artwork was used. Existing artwork ownership/licensing remains that of the original repository asset; this does not assert a new license grant.
