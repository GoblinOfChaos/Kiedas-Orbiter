# Welcome to the Cephalon Kronos Wiki

Cephalon Kronos is an open-source desktop companion for Warframe built with React, Rust, and Tauri v2. It tracks inventory, relics, rivens, mastery progress, world-state data, and helps out with OCR-powered overlays.
