# Troubleshooting

## "My inventory is empty!"
This is expected on first startup. Run a manual scan in <strong>Settings</strong> or enable live monitoring.
                    
## "Do I have to turn on Live Monitoring?"
No, you can also do manual scans in <strong>Settings</strong>. Data persists across sessions, just not updated constantly.

## "The overlay doesn't appear during fissures."
1) Confirm that notifications/overlays work via the test buttons in settings.
2) Make sure all your settings (EE.log path, UI scaling etc.) are correct and that the log scanner has latched on to Warframe.
3) Check if Riven overlays work ingame.
4) If all the above work as expected but the overlay still fails, check <code>overlay_debug.log</code> in the <code>data/user/</code> folder and report it on the [issues page](https://github.com/glowseeker/cephalon-kronos/issues)!

## "I found a bug!"
Great, please report it on the [issues page](https://github.com/glowseeker/cephalon-kronos/issues)!
